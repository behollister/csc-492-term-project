# Papers and Sources

This page tracks academic papers and other authoritative sources relevant to the project. Prefer peer-reviewed papers, primary research, standards, and official technical documentation.

## Research questions

The literature review should help answer:

1. What approaches currently address the selected problem?
2. What algorithms, architectures, or tools do those approaches use?
3. How were existing approaches evaluated?
4. What limitations or open problems remain?
5. What opportunity does this project address?
